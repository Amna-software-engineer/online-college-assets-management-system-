# 🏫 Online College Assets Management System
### A MERN Stack Solution for Institutional Inventory & Audit Tracking
This is my **Final Project** developed during my **MERN Stack Internship at U Devs**. It is designed to digitize and streamline how colleges manage their physical assets, replacing old manual registers with a professional, role-based dashboard system.

---

## 🚀 Key Features
- **Dual Dashboards:** Specialized interfaces for **Principals** (Full Oversight) and **HODs** (Department Specific).
- **Asset Lifecycle Tracking:** Monitor assets from 'New' to 'Maintenance', 'Damaged', or 'Lost'.
- **Departmental Auditing:** Automated tools for HODs to verify inventory at the end of each semester.
- **Secure Authentication:** JWT-based login with role-protected routes.
- **Smart Reporting:** Easily export asset lists and inventory data to CSV for offline record-keeping.

---

## 🛠 Tech Stack
- **Frontend:** React.js, Tailwind CSS, Lucide Icons (for UI/UX)
- **Backend:** Node.js, Express.js
- **Database:** MongoDB (Mongoose for Schema modeling)
- **State Management:** Redux Toolkit
